## 🎯 Быстрый старт для пользователей

После клонирования репозитория:

```bash
git clone https://github.com/YOUR_USERNAME/edu-ai.git
cd edu-ai

# Одна команда — запуск всего!
bash start-all.sh
```

Это:
1. Установит node_modules (если нет)
2. Создаст Python venv для Silero (если нет)
3. Запустит Silero TTS на порту 8765
4. Запустит Vite dev server на порту 3000
5. Покажет ссылки и инструкции

**Остановка:**
```bash
bash stop-all.sh
```

## 📝 Что нужно сделать перед публикацией

### 1. Замени YOUR_USERNAME на свой GitHub username

```bash
cd /Users/baxram/template-project/edu-ai

# Автоматическая замена во всех файлах
find . -name "*.md" -type f -exec sed -i '' 's/YOUR_USERNAME/твой_username/g' {} +

# Или вручную в каждом файле:
# - README.md (5 мест)
# - CONTRIBUTING.md (3 места)
# - CHANGELOG.md (3 места)
# - BAŞLANĞIC.md (1 место)
```

### 2. Обнови контакты в README.md

Найди секцию **Contact** и замени:
```markdown
- **Email:** your.email@example.com
- **GitHub:** [@YOUR_USERNAME](https://github.com/YOUR_USERNAME)
```

### 3. Проверь что всё работает

```bash
# Тест запуска
bash start-all.sh

# Открой http://localhost:3000
# Нажми F12 → Console
# Нажми "Səs açıq"
# Должна заговорить!

# Остановка
bash stop-all.sh
```

### 4. Инициализация Git (если еще не сделано)

```bash
cd /Users/baxram/template-project/edu-ai

git init
git add .
git commit -m "Initial commit: EduAI v1.0.0"
```

### 5. Создай репозиторий на GitHub

1. https://github.com/new
2. Название: **edu-ai**
3. Описание: **Interactive 3D AI Teacher with Azerbaijani TTS**
4. Public (или Private)
5. **НЕ** создавай README/LICENSE/.gitignore (уже есть локально)
6. Create repository

### 6. Push на GitHub

```bash
git remote add origin https://github.com/твой_username/edu-ai.git
git branch -M main
git push -u origin main
```

## 🔒 Что НЕ попадет на GitHub

Благодаря `.gitignore`:
- ✅ `node_modules/` (библиотеки — 200+ MB)
- ✅ `silero-server/venv/` (Python окружение)
- ✅ `*.log` (логи серверов)
- ✅ `.DS_Store` (системные файлы macOS)
- ✅ `bun.lock` (lock файл)
- ✅ `dist/` (сборка — генерируется через `npm run build`)
- ✅ `.cache/` (кеш Silero модели — 120 MB)
- ✅ `*.pdf` (большие PDF файлы)

Пользователи скачают через:
```bash
npm install              # → node_modules
cd silero-server && bash setup.sh  # → venv + модель
```
