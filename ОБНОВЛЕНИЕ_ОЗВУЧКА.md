## Как работает

### 1. Выделение текста
```
Пользователь выделяет: "DOM"
       ↓
buildExplanation() → "DOM — Document Object Model. DOM браузерин HTML sənədini..."
       ↓
SelectionTooltip показывает карточку
       ↓
onSpeak(текст_объяснения)
       ↓
App.jsx → speakText() → voiceService.js → Silero TTS
       ↓
🔊 Девушка говорит: "DOM — Document Object Model nədir? DOM brauzerin..."
```

### 2. Условие озвучивания

Девушка говорит **ТОЛЬКО** если:
- ✅ Звук включен (`soundEnabled = true`)
- ✅ Текст выделен (>= 3 символа)
- ✅ Tooltip появился

Если звук выключен (`soundEnabled = false`):
- ❌ Tooltip показывается
- ❌ Но **не озвучивается**

---

## Что озвучивается

Формат:
```javascript
const speechText = `${title}. ${body}${tip ? ` ${tip}` : ''}`
```

**Пример для "DOM":**
```
"DOM — Document Object Model. DOM браузерин HTML sənədini yaddaşda ağac şəklində təmsil etməsidir. 
Hər HTML elementi bir node (düyün) olur. JavaScript bu ağac üzərindən elementləri tapır, dəyişdirir, 
əlavə edir. DOM dəyişdirildikdə brauzer avtomatik ekranı yeniləyir."
```

**Код НЕ озвучивается** — только title + body + tip.

## Изменённые файлы

### 1. `src/components/SelectionTooltip.jsx`

**Добавлен параметр `onSpeak`:**
```javascript
export default function SelectionTooltip({ hint, onDismiss, onSpeak }) {
  // ...
  useEffect(() => {
    if (hint) {
      const exp = buildExplanation(hint.text)
      
      // NEW: Speak the explanation
      const speechText = `${exp.title}. ${exp.body}${exp.tip ? ` ${exp.tip}` : ''}`
      console.log('[SelectionTooltip] Speaking explanation:', speechText.substring(0, 50) + '...')
      onSpeak?.(speechText)
      
      // ... rest of tooltip rendering
    }
  }, [hint])
}
```

### 2. `src/App.jsx`

**Передаём callback в SelectionTooltip:**
```javascript
<SelectionTooltip 
  hint={selectionHint} 
  onDismiss={() => setSelectionHint(null)}
  onSpeak={(text) => {
    // Speak only if sound enabled
    if (soundEnabled) {
      console.log('[App] SelectionTooltip triggered speech')
      speakText(text, true) // force=true
    } else {
      console.log('[App] SelectionTooltip speech skipped (sound disabled)')
    }
  }}
/>
```

## FAQ

### Q: Девушка не говорит когда выделяю текст
**A:** Проверь:
1. Кнопка **"Səs açıq"** (зелёная) включена?
2. Silero сервер запущен? `curl http://localhost:8765/health`
3. В консоли видишь `[App] SelectionTooltip triggered speech`?
4. Если видишь `speech skipped (sound disabled)` — включи звук

### Q: Как озвучить без включения звука?
**A:** Нельзя. Это задуманное поведение — пользователь контролирует звук.

### Q: Можно озвучивать только короткие объяснения?
**A:** Можно добавить проверку длины:
```javascript
onSpeak={(text) => {
  if (soundEnabled && text.length < 500) { // макс 500 символов
    speakText(text, true)
  }
}}
```

### Q: Как остановить озвучивание?
**A:** 
- Закрой tooltip (кнопка X)
- Выключи звук (кнопка "Səs açıq")
- Нажми на другую позицию (visual/text/ring)
