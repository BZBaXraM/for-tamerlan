## Проблема
**"Она не разговаривает - я не слышу ничего"**

## Что было не так
Когда ты нажимал кнопку **"Səs açıq"**, звук включался, но модель **не начинала говорить**. Нужно было еще кликнуть на визуал/текст/кольцо.

## Что исправлено

### 1. Автоматическое воспроизведение ✅
Теперь когда ты нажимаешь **"Səssiz"** → **"Səs açıq"**, модель **сразу начинает говорить** текущую позицию (visual/text/ring).

**Код:**
```javascript
// App.jsx — toggleSound()
setSoundEnabled(true)
setTimeout(() => {
  speakCurrentFocus(focusPosition, null, force=true)  // force bypasses soundEnabled check
}, 100)
```

### 2. Подробное логирование 🔍
Добавлены логи в браузерную консоль (F12 → Console):
- `[voiceService]` — все этапы TTS (Silero fetch, audio.play, Web Speech fallback)
- `[App]` — когда вызывается speakText

Теперь ты видишь **почему** звук не играет (если проблема есть).

### 3. Тестовая страница 🧪
Создан **test-tts.html** — простой HTML без React для проверки Silero:

## Если не слышно звук

### 1. Громкость системы
- Увеличь громкость на компьютере
- Проверь что звук не выключен (иконка 🔊 в браузере)

### 2. Браузер блокирует autoplay
**Ошибка в консоли:**
```
NotAllowedError: play() failed because the user didn't interact
```

**Решение:** 
- Кликни **ЛЮБУЮ** кнопку на странице СНАЧАЛА
- Потом нажми "Səs açıq"

Chrome/Safari требуют взаимодействие пользователя перед воспроизведением аудио.

### 3. Silero server не запущен
**В консоли видишь:**
```
[voiceService] ⚠️ Silero unavailable, falling back to Web Speech
```

**Решение:**
```bash
cd /Users/baxram/template-project/edu-ai/silero-server
bash start.sh
```

Обнови страницу (Cmd+R или F5).
